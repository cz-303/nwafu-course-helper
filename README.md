# NWAFU 研究生选课助手

在 Microsoft Edge 中通过 Tampermonkey 运行的用户脚本。根据课程列表可见内容监测容量，在发现余量时尝试点击目标课程的“选课”按钮。

本项目非学校官方产品。页面适配来自截图，尚未在真实登录状态下进行端到端测试。

## 功能

- 默认课程优先级：`6091014`、`7263001`、`7264010`、`7264016`，可在面板修改。
- 默认每 60 秒整页刷新；刷新后在同一标签页恢复监测，每轮最长 2 小时。
- 等待异步课程表加载，20 秒仍无法识别时停止。
- 登录失效、登录页面、未知容量格式时暂停，不会持续刷新登录页。
- 支持仅提醒，或发现余量后自动点击一次“选课”。
- 在提交前停止刷新并清除自动恢复状态，避免重复点击。
- 匹配多个教学班时暂停；当前页缺少目标课程时明确提示。
- 不保存账号、密码，不上传数据，不直接调用选课接口。

## 安装与使用

1. 在 Edge 安装并启用 Tampermonkey，允许它访问 `https://newxsxk.nwafu.edu.cn/`。
2. 禁用或删除旧版选课脚本，避免两个脚本同时刷新或提交。
3. 新建脚本，用 `nwafu-course-helper.user.js` 的全部内容替换编辑器模板并保存。
4. 正常登录 [选课系统](https://newxsxk.nwafu.edu.cn/yjsxkapp/sys/xsxkapp/course.html)，手动完成验证码。
5. 打开课程列表，设置筛选条件，让目标教学班显示在当前页。
6. 在右下角面板检查课程号、刷新间隔和自动点击选项，点击“开始监测”。

首次使用建议取消自动点击，先验证目标课程与容量读取是否正确。保持浏览器运行；电脑休眠或浏览器对后台标签页限速，会影响检查时机。

## 选课与登录行为

“已满”视为不可选；`a/b` 按“已选人数 / 总容量”解释，仅 `0 <= a < b` 时触发。这个含义来自截图推断，请在实际页面确认。其他格式暂停处理。

发现可选课程后，脚本按优先级尝试一门并暂停，不会自动认定选课成功。确认弹窗需本人处理，之后到“已选课程”核对；成功后从面板删除该课程，再启动以监测剩余课程。失败则根据系统提示处理冲突、限制等问题。

登录失效后返回首页，手动输入验证码登录，再回课程页重新开始。脚本不能保证会话持续有效。此前出现的“未登录”提示只能证明会话失效，不能仅凭截图确定是刷新频率、固定超时还是其他原因。

刷新可能重置筛选和页码。脚本只检查刷新后实际显示的页面，不翻页，也不恢复筛选条件。请确认目标课程在刷新后仍可见。

## 限制与故障排查

- 当前适配具有“课程 / 容量 / 操作”表头的 HTML 表格；页面结构变化时可能需要重新适配。
- 无面板：确认脚本启用、网址在匹配域名内，并查看扩展对网站及用户脚本的运行授权。
- 未识别到课程表：确认当前确实是课程列表页；页面若使用非 table 结构，需要根据实际 DOM 修改。
- 登录过期：脚本暂停是预期行为，重新登录再启动。
- 出现同课号多个教学班：先在网页筛选到唯一教学班。
- 不会自动点击全局“确定”按钮，以免误确认其他操作。
- 不保证抢课成功；容量、课程冲突、选课时段和资格均以系统结果为准。请遵守学校选课规则。
